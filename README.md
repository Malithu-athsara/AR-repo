AR Car Showroom
Hiro-marker AR scene built with A-Frame 1.3.0 and AR.js 3.4.5.

Features
Rotating turntable with car model, bouncing ball, tappable box, text label
Tap the ball to change its colour; tap the box to grow/shrink it
Status banner shows whether the marker is found or lost
